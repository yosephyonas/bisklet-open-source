# Bisklet

Bisklet is an Ethiopian bike-sharing software project focused on practical and affordable urban mobility.

This repository contains the Flutter rider application. The wider architecture uses a Laravel API and a Go TCP gateway for smart bicycle locks. It has been tested against live hardware, but this repository does not claim widespread public adoption or an active public fleet.

## Features

- Rider onboarding and multilingual interfaces
- Bike location map and ride tracking
- Ride history, passes, payments and safety information
- API integration designed for a local development backend

## Develop locally

Requirements: Flutter with Dart 3.9.2 or later, and the SDKs for your target platform.

```bash
flutter pub get
flutter analyze --no-fatal-infos --no-fatal-warnings
flutter test
flutter run --dart-define=API_BASE_URL=http://127.0.0.1:8000
```

On the Android emulator, use `http://10.0.2.2:8000` instead. Use HTTPS for any non-local backend. The client restricts requests to the approved API origin. Development HTTP is unavailable in release mode.

Map services require your own approved public mapping token. Never embed private downloads tokens, production secrets, or real rider identifiers in a distributed mobile build. The application does not bundle production credentials or automatically read a tracked `.env` file.

## Project status

The `open-source-preparation` branch is private release staging. It is **not** the public release. A clean source snapshot is generated by GitHub Actions after a source secret scan. History must not be copied into the public repository.
